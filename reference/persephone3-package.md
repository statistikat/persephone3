# persephone3: Object-Oriented Wrappers for the Seasonal Adjustment Functionality of the JDemetra+ R Ecosystem rjdverse

This package is an object oriented wrapper around the R Packages rjd3x13
and rjd3tramoseats, which performs time series adjustments with the java
library JDemetra+.
