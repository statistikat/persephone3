# Interactive Seasonal, Irregular, and Calendar Effects Plot

The function generates an interactive time series plot of the seasonal
component, irregular component and calendar effects for a
[persephone](https://statistikat.github.io/persephone3/reference/persephone.md)
object together with one year forecasts.

## Usage

``` r
plotSeasIrrCalHc(x)
```

## Arguments

- x:

  an object of class
  [persephone](https://statistikat.github.io/persephone3/reference/persephone.md)

## Value

An object of class `highchart`
